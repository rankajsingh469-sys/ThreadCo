#  ThreadCo


**ThreadCo** is a modern, responsive fashion e-commerce website built to give visitors a clean and enjoyable shopping experience — from discovering products to exploring individual product details.

Built with HTML, CSS & JavaScript, ThreadCo focuses on responsive design, smooth interactions, and a simple fashion-first interface.
